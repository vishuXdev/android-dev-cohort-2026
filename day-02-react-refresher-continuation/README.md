## Day 2 - React Hooks & Form Handling

**What I Learned:**
- Virtual DOM (VDOM) fundamentals and internal mechanics
- React Hooks - useState, useEffect
- Event Handling in React
- Controlled vs Uncontrolled form inputs
- Mount and Rendering difference in React lifecycle

**Key Concept:**
VDOM is how React efficiently updates the UI. Hooks let you manage state and side effects in functional components. Mount = component first appears in DOM. Rendering = component updates. Controlled inputs = React manages the input value through state.

**Challenge:**
Understanding how VDOM diffing works internally, lifecycle differences between mount and rendering, and when to use controlled vs uncontrolled inputs
